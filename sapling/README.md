# 민둥산의 묘목

바위투성이 민둥산, 강가 바위틈에 돋은 묘목 하나로 산 전체를 숲으로 되살리는 **키우기(방치형) 게임**.
`index.html` 한 파일로 PC·휴대폰 브라우저에서 바로 실행됩니다. 진행 상황은 브라우저에 자동 저장돼요.

## 노는 법
- **어미나무**를 누르면 양분이 모이고, 가만히 있어도 조금씩 쌓여요.
- 떨어진 **씨앗**을 빈 흙에 심으면 새싹 → 묘목 → 어린나무 → 큰나무로 자라요. 나무 종류는 소나무·참나무·산벚나무·자작나무 (높은 곳일수록 소나무가 많아요).
- **바위 지형**: 산의 바위는 양분을 들여 뿌리로 쪼개면 흙이 돼요. 높이 올라갈수록 바위가 많아요.
- **병충해**: 진딧물·송충이·하늘소·흰가루병이 나무에 붙어요. 빨간 표시를 눌러 떼어 내세요. 놔두면 나무가 말라 죽고 그루터기만 남아요. 흰가루병은 옆 나무로 번지고, 새도 못 고쳐요.
- **새와 새소리**: 큰나무가 늘면 박새 → 곤줄박이 → 딱새 → 꾀꼬리 → 오색딱따구리가 찾아와 노래하고 벌레를 잡아먹어요. 새소리는 녹음 파일 없이 Web Audio로 직접 합성해요 (오른쪽 위 「소리 켜기」).
- **비버**: 큰나무가 6그루가 되면 강가에 비버가 와서 나뭇가지를 물어 날라 댐과 집을 지어요. 완성되면 강이 연못이 되고 나무가 30% 빨리 자라요.
- 창을 닫아도 숲은 자라요 (최대 8시간). 자리를 비운 동안엔 새들이 벌레를 지켜 줘서 병충해가 진행되지 않아요.

## 키우기 (업그레이드)
| 이름 | 효과 |
|---|---|
| 어미나무 키우기 | 누를 때 양분 증가, 저절로 쌓이는 양분 증가 (새싹 → 숲의 어미나무) |
| 넓은 잎 | 모든 나무의 양분 +25% |
| 깊은 뿌리 | 바위를 더 빨리, 동시에 더 많이 쪼갬 |
| 씨앗 바람 | 씨앗이 30% 더 자주 떨어짐 |
| 기름진 흙 | 나무 성장 +15%, 병충해 감소 |
| 새 둥지 | 새가 한 마리 더 머물고 벌레를 더 빨리 잡음 |

## 스킬 트리 (나이테)
원소 아레나의 스킬 트리처럼 연결된 칸을 따라 열어요. 칸을 누르면 설명이 나오고, 한 번 더 누르거나 「열기」를 누르면 열려요. 「전부 되돌리기」로 쓴 나이테를 모두 돌려받을 수 있어요.

**나이테 얻는 법**: 나무가 큰나무가 될 때 +1 · 바위를 쪼갤 때 +1 · 병충해를 손으로 뗄 때 +1 · 어미나무를 키울 때 +1 · 숲 일지 항목마다 +3

| 갈래 | 칸 (나이테) | 효과 |
|---|---|---|
| 뿌리 | 깨어난 뿌리 (1) | 트리 시작 · 어미나무 양분 +20% |
| 면역 | 수액 방어막 (2) | 병충해가 갉는 속도 -25% |
| 면역 | 피톤치드 (3) | 병충해가 30% 덜 생김 |
| 면역 | 끈끈한 송진 (3) | 벌레를 한 번 덜 눌러도 떨어짐 |
| 면역 | 균근 그물 (5) | 흰가루병 절반, 번지지 않음 |
| 면역 | 새살 돋기 (5) | 건강 회복 3배, 병충해를 떼면 건강 +40 |
| 면역 | 숲의 면역 (8) | 큰나무는 진딧물·송충이에 걸리지 않음 |
| 강화 | 햇살 모으기 (2) | 모든 양분 +15% |
| 강화 | 손끝의 온기 (3) | 어미나무를 누를 때 양분 2배 |
| 강화 | 빠른 싹 (3) | 새싹·묘목 2배 빨리 자람 |
| 강화 | 겹잎 (5) | 모든 양분 +30% |
| 강화 | 씨앗 꼬투리 (5) | 씨앗이 떨어질 때 1개 더 |
| 강화 | 거목 (8) | 큰나무 양분 1.6배 |
| 자연의 벗 | 새 모이 (2) | 새가 벌레를 50% 더 빨리 잡음 |
| 자연의 벗 | 바위 이끼 (3) | 바위 쪼개기 양분 -30% |
| 자연의 벗 | 지렁이 친구 (3) | 바위를 50% 더 빨리 쪼갬 |
| 자연의 벗 | 비버의 이웃 (5) | 비버가 큰나무 4그루면 오고, 집을 2배 빨리 지음 |
| 자연의 벗 | 새들의 합창 (8) | 머무는 새 한 마리마다 모든 양분 +6% |

예전 저장이 있으면 지금까지 키운 큰나무·쪼갠 바위·숲 일지만큼 나이테를 채워 줘요.
