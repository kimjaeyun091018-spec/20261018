# 원소 아레나 (Element Arena)

도트 탑뷰 액션 게임. 원소 스킬을 엮어 **반응**을 터뜨리고, 대난투처럼 **%가 쌓일수록 멀리 날아가는** 넉백으로 적을 구덩이에 떨어뜨리세요.
PC와 모바일 브라우저에서 바로 실행되고, 친구와 방 코드로 함께할 수 있습니다 (최대 4명).

## 모드
- **스토리 모드** — 3장 × 5스테이지 (5번째는 보스). 한 화면 경기장에서 웨이브를 빠르게 돌파 → 상자에서 골드 → 다음 스테이지. 골드로 **스킬 트리**를 강화합니다 (스토리에만 적용). 쓰러진 동료 옆에 서 있으면 부활.
- **콜로세움** — 체력 대신 %가 쌓이는 대전. 목숨 3개, 링아웃으로 승부. 1:1 / 2:2 / 4인 난투 (봇) 또는 온라인 방. 공정하게 스킬 트리는 꺼집니다.

## 캐릭터 12명
불꽃 기사 · 번개 궁수 · 서리 마법사 · 바람 닌자 · 대지 수호자 · 물의 사제 · 그림자 저격수 · 독 연금술사 · 용암 광전사 · 폭풍 무녀 · 심연의 사신 · 파도 해적
(각자 기본 공격 + 스킬 3개, 원소 8종)

## 조작
- PC: WASD 이동 · 마우스 조준 · 클릭(J) 기본 공격 · Q/E/R 스킬 · Space 대시 · Esc 일시정지
- 모바일: 왼쪽 조이스틱 · 오른쪽 버튼 (가장 가까운 적 자동 조준)

## 구조
| 파일 | 내용 |
|---|---|
| `src/data.js` | 모든 수치 (캐릭터·스킬·적·보스·반응·스킬 트리). 밸런스는 여기만 고치면 됨 |
| `src/maps.js` | 경기장 지도 (`#` 벽 · `o` 구덩이 · `^` 가시 · `P` 시작 자리) |
| `src/sim.js` | 게임 규칙 (방장이 계산). 넉백·반응·충돌·스킬·적 AI·보스·스토리·콜로세움 |
| `src/fx.js` | 기술 이펙트 · 투사체 · 지대 · 입자 |
| `src/render.js` | 지도 · 캐릭터 · 적 · HUD 그리기 |
| `src/audio.js` | 효과음 (WebAudio 합성, 파일 없음) |
| `src/net.js` | PeerJS P2P 연결 (방장 = 서버) |
| `src/ui.js`, `src/main.js` | 메뉴, 입력, 루프 |
| `tools/make_heroes.py` | 영웅 도트 그림 생성 → `assets/heroes.png` |

## 실행 / 배포
- 로컬: `python3 -m http.server` 후 `http://localhost:8000`
- GitHub Pages: 저장소 Settings → Pages → Branch `main` / root
- 파일을 고친 뒤 `python3 tools/bump_version.py` 로 캐시 번호를 올리면 휴대폰에서도 새 버전이 바로 보입니다.
