# 원소 아레나 (Element Arena)

도트 탑뷰 액션 게임. 원소 스킬을 엮어 **반응**을 터뜨리고, 대난투처럼 **%가 쌓일수록 멀리 날아가는** 넉백으로 적을 공허(맵 밖·구덩이)에 떨어뜨리세요.
영웅은 체력 대신 %가 쌓이고, 공허에 떨어지면 목숨이 하나 줄어요. 시간이 지나면 땅이 무너지고, 새 땅이 솟고, 가로로 긴 땅이 세로로 뒤틀리기도 합니다. 스토리 지도의 벽·구덩이·가시는 매번 무작위.
PC와 모바일 브라우저에서 바로 실행되고, 친구와 방 코드로 함께할 수 있습니다 (최대 4명).

## 모드
- **스토리 모드** — 소울나이트처럼 언제나 **1-1부터 시작해 3-5까지 한 판**으로 이어짐 (장마다 5번째는 보스, 장이 바뀔 때 목숨 +1·% 회복). 전멸하면 다시 1-1부터. 한 화면 경기장에서 웨이브를 빠르게 돌파 → 상자에서 골드와 아이템(포션·하트·결정·장화·방패) → 다음 스테이지.
  1-1·1-3·2-3·3-3 클리어 후 **증강 3택1**, 1-5·2-5 보스 처치 후 **전설 증강** (같은 증강 중복 불가). 클리어하면 가운데에 **빛의 문**이 솟고, 증강을 고르면 열림. 골드로 **스킬 트리**와 **뽑기 상자**.
- **콜로세움** — 체력 대신 %가 쌓이는 대전. 목숨 3개, 링아웃으로 승부. 1:1 / 2:2 / 4인 난투 (봇) 또는 온라인 방. 공정하게 스킬 트리는 꺼집니다.

## 계정 · 저장
- 처음 들어오면 **구글로 로그인** 또는 **게스트로 시작**을 고릅니다. 메뉴 아래 계정 줄에서 언제든 구글 로그인·동기화·로그아웃.
- 구글로 로그인하면 골드·영웅·스킬 트리가 Firebase(`saves/{uid}/ea`, 본인만 읽고 쓰기)에 자동 저장되어 태블릿·PC 어디서든 이어서 할 수 있어요. 기기와 클라우드 중 더 최근 저장을 씁니다.
- 처음 쓰는 구글 계정이면 게스트로 하던 진행을 그대로 옮겨 줍니다.
- 구글 계정을 처음 연동하면 **닉네임**을 정합니다. 닉네임은 모든 사람 중에 하나뿐이에요 (`nicknames/{닉네임}` = uid, 데이터베이스 규칙이 겹치기를 막음).
- Firebase 프로젝트는 예전 던전 슈터와 같은 것(`src/config.js`)이에요. **닉네임 때문에 데이터베이스 규칙에 아래 `nicknames` 부분을 한 번 추가**해야 합니다
  (Firebase 콘솔 → Realtime Database → 규칙 → `"rules": {` 바로 아래에 붙여 넣고 게시):

```json
"nicknames": {
  "$name": {
    ".read": "auth != null",
    ".write": "auth != null && (!data.exists() || data.val() === auth.uid) && (!newData.exists() || newData.val() === auth.uid)"
  }
},
```

## 조작
- PC: WASD 이동 · 마우스 조준 · 클릭(J) 기본 공격 · Q/E/R 스킬 · Space 대시 · Esc 일시정지
- 모바일: 왼쪽 조이스틱 · 오른쪽 버튼 (가장 가까운 적 자동 조준)

## 구조
| 파일 | 내용 |
|---|---|
| `src/data.js` | 모든 수치 (캐릭터·스킬·적·보스·반응·스킬 트리). 밸런스는 여기만 고치면 됨 |
| `src/maps.js` | 경기장 지도 (`#` 벽 · `o` 구덩이 · `^` 가시 · `P` 시작 자리) |
| `src/sim.js` | 게임 규칙 (방장이 계산). 넉백·반응·충돌·스킬·적 AI·보스·스토리·콜로세움 |
| `src/fx.js` | 기술 이펙트 · 투사체 · 지대 · 입자 |
| `src/render.js` | 지도 · 캐릭터 · 적 · HUD 그리기 |
| `src/audio.js` | 효과음 (WebAudio 합성, 파일 없음) |
| `src/net.js` | PeerJS P2P 연결 (방장 = 서버) |
| `src/ui.js`, `src/main.js` | 메뉴, 입력, 루프 |
| `tools/make_heroes.py` | 영웅 도트 그림 생성 → `assets/heroes.png` |

## 실행 / 배포
- 로컬: `python3 -m http.server` 후 `http://localhost:8000`
- GitHub Pages: 저장소 Settings → Pages → Branch `main` / root
- 파일을 고친 뒤 `python3 tools/bump_version.py` 로 캐시 번호를 올리면 휴대폰에서도 새 버전이 바로 보입니다.
