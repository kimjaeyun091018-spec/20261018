# ♠ 포커 — 텍사스 홀덤 · 7포커

조커 없는 52장 덱으로 하는 포커 게임. 시작 화면에서 **텍사스 홀덤** 또는 **7포커(한국식)**를 고르고 봇 1~5명과 대결해요. PC와 휴대폰 브라우저에서 바로 실행돼요.

## 실행
`poker/index.html`을 브라우저로 열면 끝. 설치할 것 없음.

## 텍사스 홀덤 규칙
- 각자 카드 2장 + 공용 카드 5장(플랍 3 → 턴 1 → 리버 1) 중 가장 좋은 5장으로 족보 비교
- 시작 칩 1,000 · 블라인드 10/20에서 시작해 8판마다 올라감
- 체크 · 베팅 · 콜 · 레이즈(최소 / ½팟 / 팟 / 올인 / 슬라이더) · 폴드
- 올인이 섞이면 메인 팟·사이드 팟으로 나눠서 정산, 같은 족보는 나눠 가짐
- 내 칩이 0이 되면 패배, 상대를 모두 탈락시키면 우승

## 7포커 규칙 (한국식)
- 참가비를 내고 4장을 받아 1장 버리고 1장 오픈
- 4구 · 5구 · 6구는 앞면, 7구(히든)는 뒷면 — 카드 받을 때마다 베팅
- 보이는 카드가 가장 좋은 사람(보스)부터 베팅
- 베팅: 체크 · 삥 · 콜 · 따당 · 하프 · 다이 (한 라운드에 레이즈 4번까지)
- 족보: 로열 스트레이트 플러시 › 백 스트레이트 플러시 › 스트레이트 플러시 › 포카드 › 풀하우스 › 플러시 › 마운틴 › 백 스트레이트 › 스트레이트 › 트리플 › 투페어 › 원페어 › 탑
- 족보와 숫자가 같으면 무늬로 비교: ♠ > ◆ > ♥ > ♣ (키커 없음)

## 홀덤 족보 (높은 순)
로얄 플러시 › 스트레이트 플러시 › 포카드 › 풀하우스 › 플러시 › 스트레이트 › 트리플 › 투페어 › 원페어 › 하이카드

## 봇
봇은 남은 카드를 수백 번 무작위로 깔아 보는 방식(몬테카를로)으로 승률을 계산하고, 팟 오즈와 비교해서 폴드·콜·레이즈를 정해요.
봇마다 성격(타이트함·공격성·블러핑 빈도)이 달라요.

## 파일
- `index.html` — 화면
- `style.css` — 테이블·카드 디자인
- `poker.js` — 덱, 홀덤 족보 판정, 베팅·사이드 팟, 봇, 화면 그리기
- `seven.js` — 7포커: 한국식 족보, 버리기·오픈, 삥/따당/하프, 7포커 봇
